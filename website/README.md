# Proverbs Dictionary

A static SvelteKit site that renders 8,000+ proverbs from JSON files, organized by their initial letter. Each page shows the proverb text and an associated image.

## Features

- **Static-first**: Pre-renders all routes into plain HTML/CSS (no server runtime required).
- **Slug-based routing**: Each proverb is accessible at `/proverbs/[proverb_id]`.
